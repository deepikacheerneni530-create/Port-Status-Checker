# Port Status Checker

## Project Description
Port Status Checker is a Python-based
network security utility.

It checks TCP ports on a local or private
target host and identifies their status.

## Objective
To audit network ports using Python
socket programming.

## Technologies Used
- Python
- Socket Programming
- TCP Protocol
- VS Code

## Features
- Accepts target IP address
- Accepts port range
- Checks TCP connections
- Identifies Open and Closed ports
- Reports filtered or unresponsive ports
- Saves execution logs

## How to Run

1. Install Python.
2. Open the project in VS Code.
3. Open the terminal.
4. Run:

python port_checker.py

## Output
Displays port status in a table and
saves results in execution_log.txt.

## Disclaimer
Use this tool only on systems you own
or have explicit permission to test.
